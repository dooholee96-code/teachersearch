# 전북 미술 교사 티오 알리미

전북특별자치도교육청 게시판 3곳과 전북 사립 중·고 홈페이지를 확인해서, 미술 관련 새 글이 올라오면 텔레그램으로 알려 줍니다.

| 게시판 | 무엇이 올라오나 | 알림 기준 |
| --- | --- | --- |
| 인력풀 > 채용공고 | 기간제·시간강사 공고 (공립·사립 학교 모두) | 과목/분야에 '미술' |
| 인력풀 > 채용계획 사전공개 | 기간제 채용 최소 7일 전 예고 | 제목·첨부파일명에 '미술', 또는 과목이 안 적힌 중등 글 |
| 도교육청 > 중등임용시험 | 공립 임용 + 사립 위탁 채용 공고 | 새 글 전부 |
| 전북 사립 중·고 홈페이지 (하루 1번) | 교육감 승인을 받아 학교가 직접 뽑는 예외 채용 등 | 첫 화면·'채용' 메뉴의 글 제목에 '미술'+'채용/모집' 등, 또는 과목 없는 '신규교사 채용' |

알림 종류: 🎨 미술 공고 · 🟡 과목 미기재(확인 필요) · 📢 임용 게시판 새 글 · 🏫 사립학교 홈페이지 글 · ⚠️ 알리미 고장

게시판은 매일 08:00, 21:00 두 번, 사립학교 홈페이지는 아침에 한 번 확인합니다 (아침에 실패하면 저녁에 다시).
사립 중·고 목록과 홈페이지 주소는 나이스 교육정보 개방포털에서 일주일마다 새로 받아서 폐교·통합이 자동 반영됩니다. 비용은 없습니다. (GitHub 예약 실행은 서버 사정에 따라 몇 분~수십 분 늦게 시작될 수 있습니다.)

## 설치 (PC에서 약 20분)

### 1단계. 텔레그램 봇 만들기

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작 → `/newbot` 입력
2. 봇 이름과 아이디(끝이 `bot`)를 정하면 **토큰**을 줍니다 (`123456:ABC...` 형태). 복사해 두세요.
3. 알림 받을 **채팅 ID** 확인
   - **부부가 같이 받기 (추천)**: 텔레그램에서 새 그룹을 만들고 아내분과 봇을 초대 → 그룹에 `/start@봇아이디` 입력
   - **혼자 받기**: 만든 봇과의 대화창에서 아무 말이나 보내기
   - 그다음 브라우저 주소창에 `https://api.telegram.org/bot<토큰>/getUpdates` 입력 → `"chat":{"id":` 뒤의 숫자를 복사 (그룹은 `-`로 시작하는 숫자, 마이너스까지 포함)

### 2단계. GitHub 저장소 만들기

1. github.com 가입 → 오른쪽 위 **+ → New repository**
2. 이름은 아무거나 (예: `art-tio`), **Private** 선택 → Create repository
3. **Add file → Upload files** 로 `monitor.py`, `requirements.txt`, `README.md` 올리고 Commit
4. **Add file → Create new file** → 파일 이름 칸에 `.github/workflows/monitor.yml` 을 그대로 입력 → `monitor.yml` 내용을 붙여넣고 Commit
   (점으로 시작하는 폴더는 업로드가 잘 안 돼서 이 방법이 확실합니다)

### 2-1단계. 나이스 인증키 받기 (사립학교 홈페이지 감시용)

1. open.neis.go.kr (나이스 교육정보 개방포털) 회원가입 후 로그인
2. 인증키 신청 메뉴에서 Open API 인증키 발급 (활용 용도는 '개인 알림용' 정도로 적으면 됨)
3. 발급된 인증키 복사

인증키를 등록하지 않으면 사립학교 홈페이지 확인만 건너뛰고 나머지는 그대로 동작합니다.

### 3단계. 비밀값 등록

저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서 두 개 등록

| Name | Secret |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | 1단계의 토큰 |
| `TELEGRAM_CHAT_ID` | 1단계의 채팅 ID (여러 개면 쉼표로: `-100123,98765`) |
| `NEIS_API_KEY` | 2-1단계의 나이스 인증키 |

### 4단계. 첫 실행으로 확인

1. 저장소 **Actions** 탭 → 왼쪽 **미술 티오 알리미** → **Run workflow**
2. 1~2분 뒤 텔레그램에 **✅ 미술 티오 알리미 시작** 메시지가 옵니다.
3. 게시판 3개와 사립 중·고 홈페이지가 모두 ✅ 인지 확인하세요. 최근 14일 안의 관련 글이 있으면 이어서 옵니다.
4. 이어서 **🏫 사립 중·고 홈페이지 첫 확인** 메시지로 몇 곳이 정상으로 읽혔는지, 접속 실패한 학교가 어디인지 알려 줍니다.
   처음 보는 학교는 옛 글이 한꺼번에 오지 않도록, 올해·내년 미술 채용 글만 알립니다.

이후로는 자동으로 돕니다.

## 문제가 생기면

**시작 메시지에서 '중등임용시험 게시판'만 ❌ (다른 게시판이 열림)**
교육청 누리집 → 알림마당 → 시험/채용/구직 → 중등임용시험 에 들어가서 주소창의 `menuCd=` 값을 복사 → `monitor.py` 의 `BOARDS` → `"exam"` 주소에 있는 `menuCd` 값을 바꿔 주세요.

**세 게시판 모두 ❌ (접속 실패·시간 초과)**
교육청 사이트가 해외 서버(GitHub)를 막는 경우입니다. 아래 '집 PC에서 돌리기'로 바꾸세요.

**Actions 로그에 `push` 권한 오류**
Settings → Actions → General → Workflow permissions → **Read and write permissions** 선택 후 저장

**사립 중·고 홈페이지가 절반 넘게 ❌**
GitHub 서버에서 학교 홈페이지 접속이 막히는 경우일 수 있습니다. '집 PC에서 돌리기'로 바꾸면 대부분 해결됩니다. 몇 곳만 실패하는 건 학교 사이트 사정이라 신경 쓰지 않아도 됩니다 (Actions 로그에 학교별 실패 이유가 남습니다).

**⚠️ 알리미 점검 필요 메시지**
같은 게시판이 2번 연속(약 반나절) 실패하면 옵니다 (12시간에 한 번만). 사이트 점검일 수도 있으니 하루 정도 지켜보고, 계속되면 위 항목을 확인하세요.

## 집 PC에서 돌리기 (대안)

1. python.org 에서 Python 설치 (설치 화면에서 'Add python.exe to PATH' 체크)
2. 이 폴더에서 명령 프롬프트 열고 `pip install -r requirements.txt`
3. 테스트: `python monitor.py --dry-run` (보낼 메시지만 화면에 출력. 사립학교까지 보려면 `NEIS_API_KEY` 환경변수를 먼저 설정)
4. 환경변수 등록 (한 번만)
   ```
   setx TELEGRAM_BOT_TOKEN "토큰"
   setx TELEGRAM_CHAT_ID "채팅ID"
   setx NEIS_API_KEY "나이스인증키"
   ```
5. Windows **작업 스케줄러** → 작업 만들기 → 트리거를 매일 08:00, 매일 21:00 두 개 추가 → 프로그램 `python`, 인수 `monitor.py`, 시작 위치는 이 폴더

## 바꾸고 싶을 때

- **키워드 추가**: `monitor.py` 맨 위 `KEYWORDS = ["미술"]` 에 단어 추가 (예: `"디자인"`, `"공예"`)
- **실행 시간**: `monitor.yml` 의 `cron` (UTC 기준이라 한국 시간에서 9시간을 빼야 함)
- **실행량**: 사립학교 확인을 포함해 한 달 약 100~150분으로, Private 저장소 무료 한도(월 2,000분) 안입니다.

## 코드를 고칠 때 (테스트)

```
pip install -r requirements-dev.txt
python -m pytest -q
```

실제 사이트에 접속하지 않고, 게시판 구조를 본뜬 가짜 페이지로 판정 규칙을 확인합니다.

## 아직 못 잡는 곳

- 사립학교 홈페이지에서 **첫 화면에도, '채용' 메뉴에도 보이지 않는** 게시판에만 올린 글
- 글 제목에 과목도 '신규' 같은 말도 없는 채용 글 (예: '교원 채용 공고' 제목만 있고 과목은 첨부에만 있는 경우)
- 교육지원청 누리집의 자체 채용 게시판
