# 전북·대전·충남 미술 교사 티오 알리미

전북특별자치도교육청 게시판 4곳, 전북·대전·충남의 교육청·교육지원청 누리집, 세 지역 사립 중·고 홈페이지를 확인해서, 미술 관련 새 글이 올라오면 **이메일**로 알려 주고, 지금 유효한 공고는 **현황판 웹페이지**에서 폰으로 바로 볼 수 있게 합니다. 앱 설치는 필요 없습니다.

| 어디를 보나 | 무엇이 올라오나 | 알림 기준 |
| --- | --- | --- |

알림 종류: 🎨 미술 공고 · 🟡 과목 미기재(확인 필요) · 📢 임용 관련 새 글 · 🏢 교육청·교육지원청 누리집 글 · 🏫 사립학교 홈페이지 글 · ⚠️ 알리미 고장
알림마다 앞에 `[전북]`, `[대전]`, `[충남]` 처럼 지역이 붙습니다. (전북교육청 게시판 4곳은 지역 표시가 없습니다.)

**받는 방법**
- **이메일**: 새 글이 있을 때만 실행당 한 통. 두 사람 주소를 넣으면 둘 다 받습니다. 메일 맨 아래에 현황판도 붙어 옵니다.
- **현황판 웹페이지**: `https://<GitHub아이디>.github.io/<저장소이름>/` — 지금 유효한 공고를 지역별로 보여 줍니다. 폰 홈 화면에 추가해 두면 앱처럼 열립니다. 미술 공고는 접수 마감일까지(마감일을 모르면 30일), 확인 필요 글은 14일, 임용 글은 30일 동안 보이고, 지난 공고는 90일까지 접어 둡니다.
- **텔레그램** (선택): 설정하면 같은 알림을 텔레그램으로도 보내고, 현황판 메시지를 채팅 상단에 고정해 둡니다.

**'교원 채용 공고'처럼 제목에 과목이 없는 글**은 글을 열어 본문과 첨부파일(한글 hwp·hwpx, pdf, docx, xlsx)을 읽습니다. '미술'이 나오면 🎨로 알리고, 다른 과목이 분명하면 알리지 않고, 첨부를 못 읽으면(암호·배포용 문서, 스캔 그림) 🟡로 보내면서 이유를 적어 줍니다.

게시판과 교육청·교육지원청 누리집은 매일 08:00, 21:00 두 번, 사립학교 홈페이지는 아침에 한 번 확인합니다 (아침에 실패하면 저녁에 다시).
게시판마다 주소를 여러 개(인력풀 사이트, 교육청 본사이트) 알고 있어서 하나가 안 열리면 다음 주소로 넘어갑니다.
사립 중·고 목록과 홈페이지 주소는 나이스 교육정보 개방포털에서 세 지역 것을 일주일마다 새로 받아서 폐교·통합이 자동 반영됩니다. 비용은 없습니다. (GitHub 예약 실행은 서버 사정에 따라 몇 분~수십 분 늦게 시작될 수 있습니다.)

## 설치 (PC에서 약 20분)

### 1단계. Gmail 앱 비밀번호 만들기 (알림 보내는 계정)

알림을 보낼 Gmail 계정이 필요합니다. 본인 계정을 써도 되고, 알림용으로 하나 새로 만들어도 됩니다.

1. 구글 계정 → **보안** → **2단계 인증**을 켭니다 (이미 켜져 있으면 건너뜀)
2. 같은 보안 메뉴에서 **앱 비밀번호**를 검색해 들어가서, 이름은 아무거나(예: `미술티오`) 적고 **만들기**
3. 16자리 비밀번호가 나옵니다 (`abcd efgh ijkl mnop` 형태). 복사해 두세요. 띄어쓰기는 있어도 없어도 됩니다

받는 주소는 아무 메일이나 됩니다 (네이버·다음·회사 메일 모두). 두 사람이 받으려면 쉼표로 적습니다.

### 2단계. GitHub 저장소 만들기

1. github.com 가입 → 오른쪽 위 **+ → New repository**
2. 이름은 아무거나 (예: `art-tio`), **Public** 선택 → Create repository
   (현황판 웹페이지를 무료로 쓰려면 Public이어야 합니다. 저장소에는 교육청 공고 제목과 링크만 쌓이고, 비밀번호 같은 값은 3단계의 Secrets에만 넣으니 공개돼도 새지 않습니다)
3. **Add file → Upload files** 로 `monitor.py`, `requirements.txt`, `README.md`, `docs` 폴더 안의 `index.html` 을 올리고 Commit
   (`docs/index.html` 은 업로드 화면에 폴더째 끌어다 놓으면 됩니다. 안 되면 **Add file → Create new file** → 이름 칸에 `docs/index.html` 을 입력하고 내용을 붙여넣기)
4. **Add file → Create new file** → 파일 이름 칸에 `.github/workflows/monitor.yml` 을 그대로 입력 → `monitor.yml` 내용을 붙여넣고 Commit
   (점으로 시작하는 폴더는 업로드가 잘 안 돼서 이 방법이 확실합니다)

### 2-1단계. 나이스 인증키 받기 (사립학교 홈페이지 감시용)

1. open.neis.go.kr (나이스 교육정보 개방포털) 회원가입 후 로그인
2. 인증키 신청 메뉴에서 Open API 인증키 발급 (활용 용도는 '개인 알림용' 정도로 적으면 됨)
3. 발급된 인증키 복사

인증키를 등록하지 않으면 사립학교 홈페이지 확인만 건너뛰고 나머지는 그대로 동작합니다.

### 3단계. 비밀값 등록

저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서 하나씩 등록

| Name | Secret |
| --- | --- |
| `EMAIL_FROM` | 1단계의 Gmail 주소 |
| `EMAIL_APP_PASSWORD` | 1단계의 16자리 앱 비밀번호 |
| `EMAIL_TO` | 받을 주소 (여러 개면 쉼표로: `me@gmail.com, wife@naver.com`) |
| `NEIS_API_KEY` | 2-1단계의 나이스 인증키 |

텔레그램으로도 받고 싶으면 아래 '텔레그램 추가'를 보고 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 를 더 등록합니다.

### 4단계. 현황판 웹페이지 켜기

1. 저장소 **Settings → Pages**
2. **Source**는 `Deploy from a branch`, **Branch**는 `main` / 폴더는 **`/docs`** 선택 → Save
3. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다 (`https://아이디.github.io/저장소이름/`). 이 주소를 폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다

### 5단계. 첫 실행으로 확인

1. 저장소 **Actions** 탭 → 왼쪽 **미술 티오 알리미** → **Run workflow**
2. 1~5분 뒤 **[미술 티오] 알리미 시작** 메일이 옵니다. 안 오면 스팸함을 보고, 거기 있으면 '스팸 아님'으로 옮겨 주세요
3. 메일 안의 게시판 4개, 교육청·교육지원청 누리집, 사립 중·고 홈페이지가 모두 ✅ 인지 확인하세요. 최근 14일 안의 관련 글이 있으면 같은 메일에 이어서 옵니다.
   '(예비 주소 2번 사용)'처럼 적혀 있으면 첫 주소가 안 열려 다른 주소로 읽은 것이니, 동작에는 문제가 없습니다.
4. **🏢 교육청·교육지원청 누리집 첫 확인**, **🏫 사립 중·고 홈페이지 첫 확인** 으로 몇 곳이 정상으로 읽혔는지, 접속 실패한 곳이 어디인지 알려 줍니다.
   처음 보는 누리집은 옛 글이 한꺼번에 오지 않도록, 올해·내년 글만 알립니다.
5. 현황판 웹페이지를 새로 고치면 찾은 공고가 보입니다

이후로는 자동으로 돕니다.

## 텔레그램 추가 (선택)

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작 → `/newbot` 입력
2. 봇 이름과 아이디(끝이 `bot`)를 정하면 **토큰**을 줍니다 (`123456:ABC...` 형태). 복사해 두세요.
3. 알림 받을 **채팅 ID** 확인
   - **부부가 같이 받기**: 텔레그램에서 새 그룹을 만들고 아내분과 봇을 초대 → 그룹에 `/start@봇아이디` 입력 → 그룹 설정에서 봇을 관리자로 지정 (현황판 메시지를 상단에 고정하기 위해)
   - **혼자 받기**: 만든 봇과의 대화창에서 아무 말이나 보내기
   - 그다음 브라우저 주소창에 `https://api.telegram.org/bot<토큰>/getUpdates` 입력 → `"chat":{"id":` 뒤의 숫자를 복사 (그룹은 `-`로 시작하는 숫자, 마이너스까지 포함)
4. 3단계처럼 Secrets에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 등록 (여러 채팅이면 쉼표로)

이메일 없이 텔레그램만 써도 됩니다.

## 문제가 생기면

**메일이 안 와요**
스팸함을 먼저 보세요. 그래도 없으면 Actions 탭 → 가장 최근 실행 → 빨간 ❌가 있으면 눌러서 `이메일 전송 실패` 줄을 찾습니다. `Username and Password not accepted`면 앱 비밀번호가 틀렸거나 2단계 인증이 꺼진 것입니다.

**현황판 웹페이지가 안 열려요 / '자료 없음'이라고 나와요**
4단계 Pages 설정을 확인하세요. 설정 직후에는 1~2분 걸립니다. '아직 알리미가 한 번도 돌지 않았다'고 나오면 5단계 첫 실행을 하세요.

**시작 메일에서 게시판 하나만 ❌ (다른 게시판이 열림 / 주소 확인 필요)**
교육청 누리집에서 그 게시판을 직접 열고(예: 알림마당 → 시험/채용/구직 → 중등임용시험) 주소창의 `boardId=`, `menuCd=` 값을 복사 → `monitor.py` 의 `BOARDS` 에서 해당 게시판의 첫 번째 주소에 있는 값을 바꿔 주세요.

**게시판 모두 ❌ (접속 실패·시간 초과)**
교육청 사이트가 해외 서버(GitHub)를 막는 경우입니다. 아래 '집 PC에서 돌리기'로 바꾸세요.

**Actions 로그에 `push` 권한 오류**
Settings → Actions → General → Workflow permissions → **Read and write permissions** 선택 후 저장

**교육청·교육지원청 누리집이나 사립 중·고 홈페이지가 절반 넘게 ❌**
GitHub 서버에서 접속이 막히는 경우일 수 있습니다. '집 PC에서 돌리기'로 바꾸면 대부분 해결됩니다. 몇 곳만 실패하는 건 사이트 사정이라 신경 쓰지 않아도 됩니다 (Actions 로그에 곳별 실패 이유가 남습니다).

**⚠️ 알리미 점검 필요 메시지**
같은 곳이 2번 연속(약 반나절) 실패하면 옵니다 (12시간에 한 번만). 사이트 점검일 수도 있으니 하루 정도 지켜보고, 계속되면 위 항목을 확인하세요.

**두 달 넘게 알림이 한 번도 안 올 때**
GitHub는 저장소에 60일 동안 아무 변화가 없으면 예약 실행을 자동으로 꺼 버립니다. 보통은 알리미가 현황판 데이터를 계속 갱신해서 괜찮지만, 혹시 멈췄다면 Actions 탭에서 'Enable workflow'를 누르면 됩니다.

## 집 PC에서 돌리기 (대안)

1. python.org 에서 Python 설치 (설치 화면에서 'Add python.exe to PATH' 체크)
2. 이 폴더에서 명령 프롬프트 열고 `pip install -r requirements.txt`
3. 테스트: `python monitor.py --dry-run` (보낼 메시지만 화면에 출력. 사립학교까지 보려면 `NEIS_API_KEY` 환경변수를 먼저 설정)
4. 환경변수 등록 (한 번만)
   ```
   setx EMAIL_FROM "보내는Gmail주소"
   setx EMAIL_APP_PASSWORD "앱비밀번호"
   setx EMAIL_TO "받는주소1,받는주소2"
   setx NEIS_API_KEY "나이스인증키"
   setx WEB_PAGE_URL "현황판주소(있으면)"
   ```
5. Windows **작업 스케줄러** → 작업 만들기 → 트리거를 매일 08:00, 매일 21:00 두 개 추가 → 프로그램 `python`, 인수 `monitor.py`, 시작 위치는 이 폴더

집 PC에서 돌리면 현황판 웹페이지는 자동으로 갱신되지 않습니다 (`docs/data.json`을 GitHub에 올려야 함). 메일 맨 아래의 현황판을 보면 됩니다.

## 바꾸고 싶을 때

- **키워드 추가**: `monitor.py` 맨 위 `KEYWORDS = ["미술"]` 에 단어 추가 (예: `"디자인"`, `"공예"`)
- **지역 바꾸기**: `monitor.py` 의 `NEIS_OFFICES`(사립학교를 받을 교육청 코드: 전북 P10, 대전 G10, 충남 N10, 세종 I10, 충북 M10, 전남 Q10 …)와 `OFFICE_SITES`(교육청·교육지원청 누리집 주소)에 넣거나 빼면 됩니다
- **실행 시간**: `monitor.yml` 의 `cron` (UTC 기준이라 한국 시간에서 9시간을 빼야 함)
- **실행량**: 누리집 확인을 포함해 한 달 약 300~600분으로, 무료 한도 안입니다 (Public 저장소는 Actions가 무제한, Private는 월 2,000분).

- 사립학교·교육지원청 누리집에서 **첫 화면에도, '채용' 메뉴에도 보이지 않는** 게시판에만 올린 글
- 대전·충남 교육청 누리집은 메뉴를 자동으로 찾아 읽는 방식이라, 메뉴 이름에 '채용·구인·기간제·임용·고시'가 없으면 못 찾습니다 (첫 확인 메시지의 '채용 메뉴 찾음' 수로 확인)
- 전국 통합 '온라인 교직원 채용'(edurecruit.go.kr)의 계약제교원 인력풀 공고 (로그인이 필요해 보여 넣지 않음)
